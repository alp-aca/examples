# ALP interactions with mesons and baryons at $\mathcal{O}(1/f_a)$: a general field redefinition invariant approach

[![arxiv](https://img.shields.io/badge/arXiv-2610.13671_[hep--ph]-B31B1B.svg?style=flat&logo=arxiv&logoColor=B31B1B)](https://arxiv.org/abs/2610.13671)

This folder collects the code used in the analysis of ALP interactions with baryons in chiral perturbation theory and beyond.

## Contents

1. [Effective ALP-baryon couplings](couplings.ipynb)
2. [Flavour-violating baryon decays into invisible ALPs ($\Sigma^+\to p+\mathrm{inv}$ and $\Xi^0\to\Lambda+\mathrm{inv}$)](baryons_to_inv.ipynb)
3. [Flavour-violating baryon decays into visible ALPs ($\Sigma^+\to p\mu^+\mu^-$)](sigmapmumu.ipynb)
4. [ALP decays into baryons](alpdecays.ipynb)
